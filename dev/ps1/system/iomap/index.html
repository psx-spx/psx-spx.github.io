    I/O Map

    All unofficial (i.e. not derived from Sony's own code or documentation) register names are suffixed with a question mark.

    DEV0

      1F000000h  80000h  Expansion Region (default 512 Kbytes, max 8 MBytes)
  1F000000h  100h    Expansion ROM Header (IDs and Entrypoints)

    Scratchpad

      1F800000h  400h  Scratchpad (1K Fast RAM) (Data Cache mapped to fixed address)

    System Bus Interface

      1F801000h  4  DEV0_ADDR?                 DEV0 (PIO)      Base Address (usually 1F000000h)
  1F801004h  4  DEV8_ADDR?                 DEV8 (debug)    Base Address (usually 1F802000h)
  1F801008h  4  DEV0_DELAY / DV0_DELAY     DEV0 (PIO)      Delay/Size   (usually 0013243Fh; 512Kbytes 8bit-bus)
  1F80100Ch  4  DEV1_DELAY / DV1_DELAY     DEV1 (debug)    Delay/Size   (usually 00003022h; 1 byte)
  1F801010h  4  DEV2_DELAY / DV2_DELAY     DEV2 (BIOS ROM) Delay/Size   (usually 0013243Fh; 512Kbytes 8bit-bus)
  1F801014h  4  DEV4_DELAY / DV4_DELAY     DEV4 (SPU)      Delay/Size   (usually 200931E1h)
  1F801018h  4  DEV5_DELAY / DV5_DELAY     DEV5 (CD-ROM)   Delay/Size   (usually 00020843h or 00020943h)
  1F80101Ch  4  DEV8_DELAY / DV8_DELAY     DEV8 (debug)    Delay/Size   (usually 00070777h; 128-bytes 8bit-bus)
  1F801020h  4  COM_DELAY  / COMMON_DELAY  (00031125h or 0000132Ch or 00001325h)

    Peripheral I/O Ports

      1F801040h  1/4  SIO0_DR  Joypad/Memory Card Data (R/W)
  1F801044h  4    SIO0_SR  Joypad/Memory Card Status (R)
  1F801048h  2    SIO0_MR  Joypad/Memory Card Mode (R/W)
  1F80104Ah  2    SIO0_CR  Joypad/Memory Card Control (R/W)
  1F80104Eh  2    SIO0_BR  Joypad/Memory Card Baudrate (R/W)
  1F801050h  1/4  SIO1_DR  Serial Port Data (R/W)
  1F801054h  4    SIO1_SR  Serial Port Status (R)
  1F801058h  2    SIO1_MR  Serial Port Mode (R/W)
  1F80105Ah  2    SIO1_CR  Serial Port Control (R/W)
  1F80105Ch  2    SIO1_?   Serial Port Internal Register (R/W)
  1F80105Eh  2    SIO1_BR  Serial Port Baudrate (R/W)

    DRAM Controller

      1F801060h  4/2  DRAM_CTRL?  (usually 00000B88h; 2MB RAM mirrored in first 8MB)

    Interrupt Control

      1F801070h  2  I_STAT / I_REG  Interrupt status register
  1F801074h  2  I_MASK          Interrupt mask register

    DMA Registers

      1F801080h   4  D0_MADR       Channel 0 (MDECin)  Memory Address Register (R/W)
  1F801084h   4  D0_BCR        Channel 0 (MDECin)  Block Count Register (R/W)
  1F801088h   4  D0_CHCR       Channel 0 (MDECin)  Channel Control Register (R/W)
  1F80109xh  12  D1_*          Channel 1 (MDECout) ...
  1F8010Axh  12  D2_*          Channel 2 (GPU)     ...
  1F8010Bxh  12  D3_*          Channel 3 (CD-ROM)  ...
  1F8010Cxh  12  D4_*          Channel 4 (SPU)     ...
  1F8010Dxh  12  D5_*          Channel 5 (PIO)     ...
  1F8010Exh  12  D6_*          Channel 6 (OTC)     ...
  1F8010F0h   4  DPCR / D_PCR  DMA Priority Control Register
  1F8010F4h   4  DICR / D_ICR  DMA Interrupt Control Register
  1F8010F8h   4  unknown
  1F8010FCh   4  unknown

    Timers (aka Root counters)

      1F801100h   2  T0_COUNT             Timer 0 (dotclock) Current Value (R/W)
  1F801104h   2  T0_MODE              Timer 0 (dotclock) Mode (R/W)
  1F801108h   2  T0_COMP / T0_TARGET  Timer 0 (dotclock) Target Value (R/W)
  1F80111xh  12  T1_*                 Timer 1 (hblank)   ...
  1F80112xh  12  T2_*                 Timer 2 (sysclock) ...

    CDROM Registers (Address.Read/Write.Index)

      1F801800h.R.*      1  HSTS       CD Index/Status Register (R)
  1F801801h.R.*      1  RESULT     CD Response Fifo (R)
  1F801802h.R.*      1  RDDATA     CD Data Fifo (R)
  1F801803h.R.bank0  1  HINTMSK    CD Interrupt Enable Register (R)
  1F801803h.R.bank1  1  HINTSTS    CD Interrupt Flag Register (R)
  1F801800h.W.*      1  ADDRESS    CD Index Register (Bit0-1 W)
  1F801801h.W.bank0  1  COMMAND    CD Command Register (W)
  1F801802h.W.bank0  1  PARAMETER  CD Parameter Fifo (W)
  1F801803h.W.bank0  1  HCHPCTL    CD Request Register (W)
  1F801801h.W.bank1  1  WRDATA     CD Sound Map Data (W)
  1F801802h.W.bank1  1  HINTMSK    CD Interrupt Enable Register (W)
  1F801803h.W.bank1  1  HCLRCTL    CD Interrupt Flag Register (W)
  1F801801h.W.bank2  1  CI         CD Sound Map Coding Info (W)
  1F801802h.W.bank2  1  ATV0       CD Audio Volume for Left-CD-Out to Left-SPU-Input (W)
  1F801803h.W.bank2  1  ATV1       CD Audio Volume for Left-CD-Out to Right-SPU-Input (W)
  1F801801h.W.bank3  1  ATV2       CD Audio Volume for Right-CD-Out to Right-SPU-Input (W)
  1F801802h.W.bank3  1  ATV3       CD Audio Volume for Right-CD-Out to Left-SPU-Input (W)
  1F801803h.W.bank3  1  ADPCTL     CD Audio Volume Apply Changes (by writing bit5=1)

    GPU Registers

      1F801810h.W  4  GP0  Send GP0 Commands/Packets (Rendering and VRAM Access)
  1F801810h.R  4  GP0  Read responses to GP0(C0h) and GP1(10h) commands
  1F801814h.W  4  GP1  Send GP1 Commands (Display Control)
  1F801814h.R  4  GP1  Read GPU Status Register

    MDEC Registers

      1F801820h.W  4  MDEC0  MDEC Command/Parameter Register (W)
  1F801820h.R  4  MDEC0  MDEC Data/Response Register (R)
  1F801824h.W  4  MDEC1  MDEC Control/Reset Register (W)
  1F801824h.R  4  MDEC1  MDEC Status Register (R)

    SPU Voice 0..23 Registers

      1F801C00h + 10h*N  2  VOLL   Voice 0..23 Volume Left
  1F801C02h + 10h*N  2  VOLR   Voice 0..23 Volume Right
  1F801C04h + 10h*N  2  PITCH  Voice 0..23 Sample Rate
  1F801C06h + 10h*N  2  SSA    Voice 0..23 Sample Start Address
  1F801C08h + 10h*N  2  ADSR1  Voice 0..23 ADSR Attack/Decay
  1F801C0Ah + 10h*N  2  ADSR2  Voice 0..23 ADSR Sustain/Release
  1F801C0Ch + 10h*N  2  ENVX   Voice 0..23 ADSR Current Volume
  1F801C0Eh + 10h*N  2  LSAX   Voice 0..23 Loop Start Address

  1F801D8Ch  2  KOF0       Voice 0..15  Key OFF (Start Release) (W)
  1F801D8Eh  2  KOF1       Voice 16..23 Key OFF (Start Release) (W)
  1F801D90h  2  PMON0      Voice 1..15  Channel FM (pitch lfo) mode (R/W)
  1F801D92h  2  PMON1      Voice 16..23 Channel FM (pitch lfo) mode (R/W)
  1F801D94h  2  NON0       Voice 0..15  Channel Noise mode (R/W)

  1F801D9Ch  2  ENDX0      Voice 0..15  Channel ON/OFF (status) (R)
  1F801D9Eh  2  ENDX1      Voice 16..23 Channel ON/OFF (status) (R)
  1F801DA0h  2             Unused? (R) or (W)

  1F801DB8h  2  MVOLXL     Current Main Volume Left
  1F801DBAh  2  MVOLXR     Current Main Volume Right
  1F801DBCh  4             Unused? (R/W)

    DEV8 - Int/Dip/Post

    DEV1 (default 1 byte, max 2 MBytes)

      1FA00000h  Not used by BIOS or any PSX games
  1FA00000h  POST3 (similar to POST, but PS2 BIOS uses this address)

    BIOS Region (default 512 Kbytes, max 4 MBytes)

      1FC00000h  80000h  BIOS ROM (512Kbytes) (Reset Entrypoint at BFC00000h)

    CW33300 CPU Configuration

      FFFE0130h  4  BCC  BIU/Cache Control

    Coprocessor Registers

      COP0 System Control Coprocessor           - 32 registers (not all used)
  COP1 N/A
  COP2 Geometry Transformation Engine (GTE) - 64 registers (most are used)
  COP3 N/A

    Legacy names from outdated documentation

    nocash's original version of the documentation, as well as emulators and other tools that were written using it as a reference, refer to several registers using unofficial names that have since been changed to the known official ones in this fork: 

    System bus devices:
  EXP1 / Expansion 1          --> DEV0
  EXP2 / Expansion 2          --> DEV8
  EXP3 / Expansion 3          --> DEV1

SIO0:
  JOY_TX_DATA, JOY_RX_DATA    --> SIO0_DR
  JOY_STAT                    --> SIO0_SR
  JOY_MODE                    --> SIO0_MR
  JOY_CTRL                    --> SIO0_CR
  JOY_BAUD                    --> SIO0_BR

SIO1 (often referred to as just "SIO"):
  SIO_TX_DATA, SIO_RX_DATA    --> SIO1_DR
  SIO_STAT                    --> SIO1_SR
  SIO_MODE                    --> SIO1_MR
  SIO_CTRL                    --> SIO1_CR
  SIO_MISC                    --> SIO1_?
  SIO_BAUD                    --> SIO1_BR

GPU:
  GPUREAD                     --> GP0
  GPUSTAT                     --> GP1 (BIOS refers to it as GP1 when reading)

SPU:
  SPUCNT                      --> ATTR
  SPUSTAT                     --> STATX
  DTC / Data Transfer Control --> RAM_CTRL?
  Reverb mBASE                --> ESA
  Reverb vLOUT, vROUT         --> EVOLL, EVOLR
